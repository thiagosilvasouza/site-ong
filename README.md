# ONG Mãos Solidárias

Projeto acadêmico de uma ONG fictícia, desenvolvido com HTML5,
CSS e JavaScript.

## Funcionalidades

- Navegação SPA.
- Menu responsivo e submenus.
- Campanhas geradas por template.
- Formulário com máscaras e validações.
- Modal de participação.
- Preferência de colaboração salva no localStorage.
- JavaScript organizado em módulos.

## Organização

- html/: páginas index.html, projetos.html e cadastro.html.
- css/: estilos da aplicação.
- imagens/: recursos visuais.
- js/: navegação, formulário, campanhas, modal e armazenamento.

## Como executar

Abra a pasta site-ong no VS Code e utilize o Live Server
no arquivo html/index.html.

## Fluxo Git

- main: versão estável.
- develop: integração das alterações.
- feature/: novas funcionalidades e melhorias.
- release/: preparação de versões.
- hotfix/: correções urgentes da versão estável.

Este projeto não realiza pagamentos nem envia cadastros
para um servidor.
